Week 33 Prepare: Branching Paths & Selection

Last week, we built linear flowcharts where instructions ran smoothly one after another. This week, we are looking at Selection—the moment an algorithm has to ask a question and make a decision!

The Core Rules of Selection

In computer systems, questions usually have a simple Yes (True) or No (False) answer. We use key terms to handle these branches:

📌 IF checks if a condition is met (e.g., Is the height greater than 140cm?).
📌 THEN holds the instructions that run only if the answer is Yes.
📌 ELSE holds the fallback instructions that run only if the answer is No.

In flowcharts, these questions live inside a Diamond Shape. Unlike normal rectangles, a decision diamond always has two exit arrows stretching out from it: one marked Yes and one marked No.
