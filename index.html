Week 33 Prepare: Branching Paths & Selection

Last week we built linear flowcharts where instructions ran one after another. This week we focus on Selection — the moment an algorithm asks a question and makes a decision.

1 The Core Rules of Selection

In computer systems, questions have a simple Yes (True) or No (False) answer. We use key terms to handle these two branches:

IF
The IF keyword checks whether a condition is met — e.g. Is the score greater than 5?
TH
The THEN block holds instructions that run only if the condition is True.
EL
The ELSE block holds fallback instructions that run only if the condition is False.

In flowcharts, decision questions live inside a ◆ Diamond. Unlike rectangles, a decision diamond always has two exit arrows: one labelled Yes and one labelled No.
